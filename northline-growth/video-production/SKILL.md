# Video-Produktion (Drehtag bis Reel)

Deine Aufgabe: **Qualitäts-Videoinhalte** produzieren — vom Drehtag vor Ort über Schnitt bis zur fertigen Reel, optimiert für Meta Ads und Instagram.

## Das Northline-Drehtag-Modell

### Setup: 2–3 Stunden Dreh vor Ort = 3–5 Reels Output

**Wer:** Videograf/Editor + ggf. Producer (=Northline-Mitarbeiter)
**Wann:** 1x/Monat pro Kunde (synchron mit Kampagnen-Start)
**Material:** 20–30 Minuten Rohfootage, daraus entstehen 3–5 Reels

**Kosten (extern):** ~90–110 € pro Reel (Freelancer-Quote Northline)

### Drehtag Checkliste

```
VOR Drehtag (1 Woche):
☐ Kunde Brief erhalten (Was soll gezeigt werden, welche Personen?)
☐ Location Orte recce — Zeit, Wetter-Check, Lichtsituation
☐ Genehmigungen einholen (Mitgliederkennzeichnungen in Video)
☐ Ausrüstung packed: Kamera, Mic, Stabilizer, Speicherkarten, Backup

AM Drehtag:
☐ Ankunft 30 Min vor Start
☐ Equipment aufbauen + Audio-Pegel testen
☐ [Dann Dreh — siehe Skript unten]
☐ 2 Tage Buffer: Wetter-Probleme, Personen-Absagen

NACH Drehtag (24h):
☐ Rohfootage backed up auf 2 Drives
☐ Timecode-Notizen hochgeladen (was ist auf Minute 3.45, 7.23 etc.)
☐ Schnittanfrage an Editor gesendet
```

## Drehtag-Skript (Was drehen wir)

### Segment 1: Club-Atmosphäre (B-Roll) — 8 Minuten Rohfootage

```
GOAL: Zeigen, dass hier echte Menschen echten Spaß haben

Szene 1: Eingang/Empfang
- Person kommt rein, wird begrüßt (15 Sekunden)
- Wide-Shot Clubhaus (30 Sekunden)

Szene 2: Sport-Action (verschiedene Aktivitäten)
- Golfer beim Schwung (zeitlupe, mehrere Wiederholungen)
- Tennis-Match live spielend (schnelle Schnitte)
- Segeln: Boot raus, Wind, Wasser
- Dauer: 5 Minuten (= Rohfootage, wird zu mehreren Reels-Szenen)

Szene 3: Lachen, Reden, Beziehungen
- Zwei Mitglieder quatschen und lachen (30 Sekunden)
- Gruppe nach Match sitzt zusammen (1 Minute)
- Coach gibt Tipps (Nahaufnahme Gesicht, 30 Sekunden)

Szene 4: Awards/Trophäen/Club-Identity-Shots
- Trophy-Schrank, Club-Logo, Werte an Wand (1 Minute)
```

### Segment 2: Neumitglied-Testimonial — 3 Minuten Rohfootage

```
GOAL: „Echte Person spricht über ihre Erfahrung"

Setup: Helles Licht, Mitglied sitzt mit entspanntem Ausdruck

Fragen zum Beantworten (Videograf stellt sie, wird geschnitten weg):
1. „Warum bist du diesem Club beigetreten?"
2. „Was war deine größte Überraschung?" (oft: die Community)
3. „Wie lange hat es gedauert, bis du echte Freunde hattest?"
4. „Würdest du deine Freunde empfehlen?"
5. „Wie hat sich dein Leben verändert?" (optional)

Anweisungen an Person:
- Natürlich sprechen, nicht Scripts auswendig lernen
- 2–3 Takes pro Frage (Videograf braucht Material zum Schneiden)
- Lache wenn es natürlich ist, heuchteln ist schlecht
```

### Segment 3: Trainer-Tipps — 2–3 Minuten Rohfootage

```
GOAL: Educational + „Trainer ist ein echter Mensch, nicht just a face"

Setup: Trainer auf dem Court/Golfplatz, zeigt einen Fehler + Korrektur

Beispiel (Tennis):
Trainer zeigt: [FEHLER] falscher Griff beim Aufschlag
Dann: [Correction] richtiger Griff + Demo
Dann: [Practice] Student macht es, Trainer nickt

Dauer: ~3 Wiederholungen (mehrere Takes zum Schneiden)
```

## Post-Produktion: Vom Rohfilm zur Reel

### Schnitt-Workflow (48 Stunden Turnaround)

**Input:** 25–30 Min Rohfootage + Timecode-Notizen + Copy-Brief

**Output:** 3–5 Reels à 15–30 Sekunden

### Standard-Reel-Struktur

```
HOOK (0–3 Sekunden) — KRITISCH
├─ Visual: Schnelle Schnitte, visueller Kontrast, oder
├─ Text-Overlay: Sprechender Text + Musik
└─ Ziel: User stoppt Scrollen

BODY (3–20 Sekunden)
├─ Storytelling oder Progression
├─ Musik + Schnitt im Beat
└─ 2–3 Schnitte pro Sekunde (schnell ist besser als langsam)

CTA (20–30 Sekunden)
├─ Text: „Probemitgliedschaft Link in Bio"
├─ Oder: „Folge für mehr Club-Content"
└─ Musik: Ausfaden, aber nicht Fade-to-Black
```

### Konkrete Reel-Rezepte

#### Reel 1: „Community-Vibe"

```
Hook Text (0–2s): „Das ist der Grund, warum wir spielen"
(Text über Video: Mitglieder lachen, schnelle Schnitte)

Body (2–20s):
- Golfer Schwung (2s, langsam)
- Tennis Match schnelle Schnitte (3s)
- Zwei Mitglieder quatschen (2s)
- Coach mit Student (2s)
- Turniersieger mit Trophy (2s)
- Gruppe im Clubhaus, cheers (2s)

CTA Text (20–30s):
„Probemitgliedschaft 30 €
Link in Bio"

Music: Upbeat, positiv (z.B. Trending Audio Instagram)
```

#### Reel 2: „Anfänger-Transformation"

```
Hook Text: „Von ‚Ich kann nicht spielen' zu …"
(Split-Screen: verwirrtes Gesicht vs. glückliches Gesicht)

Body:
- Tag 1: Neumitglied nervös, Trainer zeigt Basics (4s)
- Tag 15: Mitglied spielen, besser Formkontrolle (4s)
- Tag 30: Mitglied lacht, spielt sicher (4s)
- Friends: Neue Freunde spielen zusammen (3s)

CTA: „Das kannst du auch.
Link in Bio"

Music: Inspirational
```

#### Reel 3: „Educational Quick-Tip"

```
Hook Text: „Der häufigste Anfänger-Fehler"
(Slow-Motion: Tennis falscher Schlag)

Body:
- Fehler gezeigt (2s)
- Trainer erklärt (3s Text-Overlay)
- Richtige Technik Demo (3s)
- Richtige Technik mit Student (3s)

CTA: „Trainings-Kurs buchen —
Link in Bio"

Music: Minimal, fokussiert
```

#### Reel 4: „Testimonial-Kurz"

```
Hook Text: „Wie lange hat es gedauert, neue Freunde zu finden?"
(Portrait Neumitglied, Studio-Setup)

Body:
- Mitglied spricht (4s Zitat)
- Montage: Mitglied mit neuen Freunden (4s)
- Zitat-Fortsetzung (3s)
- Lachen (2s)

CTA: „Neugierig? Probemitgliedschaft buchen"

Music: Warm, menschlich
```

## Schnitt-Technik (Non-Negotiables)

### Untertitel (MUSS)
- Alle Videos **automatisch oder manuell untertitelt** (85% User schauen ohne Sound)
- Schriftart: Weiß mit schwarzem Rand (lesbar auf hellen/dunklen Hintergründen)
- Platzierung: Top 70% des Screens (nicht unten, da Meta-UI dort ist)
- Timing: Text synchron zur Sprache

### Schnitt-Tempo
- Schnelle Schnitte (200–400ms pro Shot) halten Aufmerksamkeit
- Musik-Beats = Schnitt-Points (schneiden zum Beat)
- Erste 2 Sekunden = höchste Schnitt-Frequency (schnellste Schnitte)

### Musik + Sound
- **Quellen:** Instagram Audio Library, TikTok Sounds, Epidemic Sound (lizenzpflichtig)
- **Volumen:** Musik 70%, Sprechen 100% (Dialog überlagert Musik)
- **Fade:** Immer ausfaden, nie abrupt stoppen (Sound-Bruch)

### Qualität-Standards
- Auflösung: 1080p Minimum (2K ideal)
- Framerate: 24 oder 30fps (nicht 60fps, zu flüssig für Social)
- Farb-Grading: Konsistent über alle Schnitte (kein Flackern)
- Aspect Ratio: 9:16 (Reels) oder 1:1 (Square)

## Häufige Fehler & Fixes

| Fehler | Problem | Fix |
|--------|---------|-----|
| Langsame Schnitte | User scrollen weg (Hook-Problem) | Schnitt-Tempo 2x erhöhen (200ms statt 400ms) |
| Kein Untertitel | 85% User sehen Video ohne Sound | Automatische Captions einschalten (Meta) |
| Musik übertönt Dialog | Sprechen nicht verständlich | Dialog 100%, Musik 60–70% mischen |
| Erste 2 Sek langweilig | User scrollen weg vor Hook-Auflösung | Hook-Scene mit Visual-Kontrast starten (schnelle Schnitte, Text-Overlay) |
| Testimonial klingt geskriptet | Nicht authentisch, lässt Vertrauen fahren | 2–3 Takes pro Frage filmen, beste nehmen |
| Stock-Musik (Klavier-Standard) | Billiger Look | Trending Audio nutzen oder Epidemic Sound |

## KPI & Erfolg-Messung

**Nach Upload, nach 3–7 Tagen:**

| Metrik | Zielwert | Aktion wenn unter Ziel |
|--------|----------|-----|
| **Reach** | 5.000–15.000 | Höhere Budget in Meta-Ad oder Re-Post |
| **Play Rate** (views / impressions) | > 50% | Hook nicht stark genug — nächste Reel schneller schneiden |
| **Avg Watch Duration** | > 50% der Reels-Länge | Mid-Body Problem — Schnitte vereinfachen |
| **Shares / Saves** | > 5 | Gutes Content-Signal — reprodizieren |
| **CTR auf Link (in Beschreibung)** | > 2% | Strong Landing-Page Alignment |
