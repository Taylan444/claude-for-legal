# Design Department

Spezialisierte Claude Skills für die **visuelle Identität von Clubs** — Brand Guidelines, Design-Systeme, Farb-Palette, Typografie, Website-Redesign.

Diese Abteilung ergänzt die [Marketing-Abteilung](../README.md) mit der **strategischen visuellen Grundlage**, auf die alle anderen Teams (Social Media, Ads, Website, Print) aufbauen.

---

## 📂 Skills in dieser Abteilung

### 1. **Brand Kit für Clubs** (`SKILL-brandkit-clubs.md`)
Definiere die komplette visuelle Identität eines Clubs.

**Inhalte:**
- Brand Discovery Interview (4 Fragen zu Essence, Richtung, Farbe, Vorbild-Clubs)
- brand.md Template mit Essence, Brand Story, Visual Direction
- Farbpalette (Primär, Sekundär, Akzent) mit Hex-Codes
- Typografie (Headlines: Montserrat Bold, Body: Inter)
- Logo-Richtung (Minimalist, 2–3 Farben, skalierbar)
- Bild-Stil (Fotografie + Illustrationen)
- UI-Komponenten (Buttons, Cards, Inputs)
- Ton & Voice auf Design-Ebene

**Best für:**
- Neu-Onboarding eines Clubs (einmalig, 2–3 Stunden)
- Konsistente Basis für alle Designentscheidungen
- Dokumentation für externes Team (Webdesigner, Druckerei)

**Timing:** 30 Min Interview + 1–2 Stunden brand.md schreiben = 2–3 Stunden Setup

---

### 2. **Design-System für Clubs** (`SKILL-design-system-clubs.md`)
Baue ein einfaches, wiederverwendbares Design-System auf.

**Inhalte:**
- 4 Core Components (Header, Hero, Feature-Section, CTA-Block)
- Layout Grid (Container-Breite, Spacing, Abstände)
- Komponenten-Biblioteca (Cards, Buttons, Forms, Modals)
- Responsive Rules (Mobile First, Breakpoints)
- Accessibility Basics (Kontrast, Schriftgröße, Fokus-States)
- Component-Checkliste (vor jedem Design-Element)

**Best für:**
- Website-Designs vereinheitlichen (nicht jede Seite sieht anders aus)
- Designer-Handbuch für externe Teams
- Schnellere Website-Produktion (nicht von Grund auf neu design)

**Timing:** 1 Stunde (wenn brand.md fertig)

---

### 3. **Farb-Palette-Generator für Clubs** (`SKILL-color-palette-generator-clubs.md`)
Generiere harmonische, Club-spezifische Farbpaletten.

**Inhalte:**
- Farbpsychologie (Dunkelblau = Vertrauen, Orange = Energie, etc.)
- 5 Palette-Vorlagen (Classic, Energetic, Natural, Minimal, Bold)
- Kontrast-Checklist (WCAG AA Standard)
- Farb-Anwendung pro Element (CTA, Headlines, Backgrounds)
- Club-Typ-Vorlagen (Golf = traditionell, Tennis = energisch, etc.)
- Hex-Code-Export-Format (für Developer, Webdesigner)

**Best für:**
- Quick Farbwahl, wenn brand.md noch nicht final
- Farb-Experiment (Test verschiedener Richtungen)
- Color-Coding für Website-Sections (Navigation, Alert, Success, etc.)

**Timing:** 15–30 Min (wähle Vorlage, passe an)

---

### 4. **Typografie-Guide für Clubs** (`SKILL-typography-guide-clubs.md`)
Definiere klare, lesbare Schriftarten und Größen.

**Inhalte:**
- Font-Pairing (Headlines + Body-Text)
- Größen-Skala (H1, H2, H3, Body, Small, Labels)
- Font-Gewicht und Varianten (Regular, Medium, Bold)
- Line-Height und Letter-Spacing Rules
- Mobil-Optimierung (Größen auf Handy lesbar?)
- Fallback Fonts (wenn primäre Font nicht lädt)
- Before/After Typografie-Beispiele

**Best für:**
- Konsistente Text-Hierarchie auf Websites
- Lesbarkeit auf Mobile + Desktop sichern
- Developer-Handout (welche Font auf welchem Element?)

**Timing:** 20–30 Min (wähle Fonts, definiere Skala)

---

### 5. **Website-Redesign für Clubs** (`SKILL-website-redesign-clubs.md`)
Audit + Upgrade einer bestehenden Club-Website.

**Inhalte:**
- Website-Audit-Checklist (15 Punkte: Layout, Speed, Mobile, CTA, Design-Kohärenz)
- Common Website Sins (3+ Fonts, zu viele Bilder, schlechter Mobile, alte Fotografie)
- Section-by-Section Redesign:
  * Hero (neuer Text, besseres Bild)
  * Problem-Proof (Social Proof + Trust Signals)
  * Features/Benefits (Kurze, klare Sätze)
  * Testimonials (Echte Member-Quotes)
  * CTA (Clear Buttons, Kontrast)
  * Footer (Navigation, Social Links, Contact)
- Before/After Beispiele pro Club-Typ
- Timeline + Kosten-Schätzung (wie lange braucht's?)

**Best für:**
- Analyse der aktuellen Website
- Priorisierung: Was muss zuerst fixed werden?
- Außenteam-Brief (Webdesigner, Entwickler)

**Timing:** 30 Min Audit + 2–3 Stunden Redesign-Planung

## 🎯 Quick-Navigation nach Use-Case

### Du startest einen neuen Club:
1. **Brand Kit** → brand.md definieren (2–3 Std)
2. **Farb-Palette-Generator** → Farbpalette exportieren (15 Min)
3. **Typografie-Guide** → Fonts + Größen festlegen (20 Min)
4. **Design-System** → Website-Template bauen (1 Std)

### Du überarbeitest eine alte Club-Website:
1. **Website-Redesign** → Audit durchführen (30 Min)
2. **Design-System** → Komponenten vereinheitlichen (1–2 Std)
3. **Farb-Palette-Generator** → Farben modernisieren (15 Min)

### Du brauchst schnelle Design-Assets für Social Media:
1. **Brand Kit** → Logo-Richtung + Farben checken
2. **Farb-Palette-Generator** → Social-Media-Farben für Posts
3. **Typografie-Guide** → Text-Hierarchie für Grafiken

## 📊 Recommended Workflow (Design-Prozess)

### Phase 1: Discovery (Woche 1)
```
□ Brand Kit Interview durchführen
□ brand.md Rohversion schreiben
□ Farbpalette auswählen (Farb-Palette-Generator)
□ Fonts entscheiden (Typografie-Guide)
```

### Phase 2: System (Woche 2)
```
□ Design-System aufbauen (4 Core Components)
□ Color Swatches exportieren
□ Typography Styles dokumentieren
□ Component-Biblioteca als Vorlage erstellen
```

### Phase 3: Produktion (Woche 3+)
```
□ Website-Redesign (oder neue Website)
□ Ads-Grafiken nach Brand Kit
□ Social-Media-Templates
□ Print-Assets (Flyer, Visitenkarten)
```

---

## 🧠 Best Practices (für die Abteilung)

1. **Brand First** — Alle Design-Entscheidungen aus brand.md ableiten (nicht Geschmack)
2. **Einfach, nicht komplex** — Max 2 Fonts, 3–4 Farben, 4 Core Components
3. **Kohärenz** — Immer die gleiche Farbe für CTA, die gleiche Schrift für Headlines
4. **Mobil First** — Website auf Handy entwerfen, dann auf Desktop optimieren
5. **Accessibility** — Kontrast checken, Schrift ≥16px, ALT-Text für Bilder
