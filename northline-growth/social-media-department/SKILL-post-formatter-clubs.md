# Post Formatter für Clubs

Deine Aufgabe: Ein Thema oder Rohtext in einen **fertig-formatierten Post** umwandeln — strukturiert nach bewährten Frameworks, mobil-lesbar, mit klarem CTA.

---

## Die 5 Frameworks (schnelle Übersicht)

| Framework | Struktur | Best für | Beispiel |
|-----------|----------|----------|---------|
| **PAS** | Problem → Agitate → Solve | Lead-Gen, Tipps | Fehler zeigen, agitieren, Lösung geben |
| **AIDA** | Attention → Interest → Desire → Action | Angebote, CTAs | Hook + Grund + Warum es wertvoll ist + Link |
| **BAB** | Before → After → Bridge | Transformationen | So war's → So ist's → Das ist unser Club |
| **STAR** | Situation → Task → Action → Result | Erfolgsgeschichten | Wer war es → Was war die Herausforderung → Was tat sie → Ergebnis |
| **SLAY** | Story → Lesson → Actionable → You | Tipps & Learnings | Story erzählen → Lektion → 3 konkrete Schritte → Aufforderung |

---

## PAS Framework (Problem-Agitate-Solve)

**Best für:** Trainer-Tipps, häufige Fehler, Anfänger-Probleme

**Struktur:**
```
Problem (2 Zeilen): Was ist das Ärgerliche?
Agitate (2 Zeilen): Warum ist das so blöd?
Solve (3 Zeilen): Wie es besser geht (konkret)
CTA (1 Zeile): Link oder Aufforderung
```

**Beispiel (Tennisverein):**
```
PROBLEM
Du schlagst den Ball hart. Aber die Kontrolle? Weg.

AGITATE
Das Gefühl: Kannst spielen, aber nicht gut spielen.
Frustration nach jedem Match.

SOLVE
Der Geheimtipp: Nicht Kraft. Technik.
Ein Serve mit richtigem Grip = konsistent UND schnell.
So machen es die Profis — und so kannst du's auch.

CTA
Trainings-Video in Stories. Probier's diese Woche.
```

---

## AIDA Framework (Attention-Interest-Desire-Action)

**Best für:** Probemitgliedschaft-Angebote, Event-Anmeldungen, Angebote mit Deadline

**Struktur:**
```
Attention (1 Zeile): Hook (Zahl oder Überraschung)
Interest (2 Zeilen): Warum sollte es dich interessieren?
Desire (2 Zeilen): Was bekommst du konkret?
Action (1 Zeile): Link + CTA
```

**Beispiel (Golfclub):**
```
ATTENTION
450 neue Golfer haben dieses Jahr einen neuen Club gefunden.

INTEREST
Nicht wegen dem Platz. Sondern wegen den Menschen.
Die meisten berufstätige Unternehmer wie du.

DESIRE
3-Stunden-Probemitgliedschaft = 30 €
Danach wissen wir beide: Ist das dein Leute.

ACTION
[Link] Probemitgliedschaft buchen
```

---

## BAB Framework (Before-After-Bridge)

**Best für:** Member-Testimonials, Transformationen, „Dein Leben nach dem Club"

**Struktur:**
```
Before (2 Zeilen): So war es vorher
After (2 Zeilen): So ist es jetzt
Bridge (2 Zeilen): Warum der Club der Unterschied war
```

**Beispiel (Segelclub):**
```
BEFORE
Julia: „Ich war allein in der Stadt. Keine Freunde. Kein Hobby."

AFTER
Heute: Segelt 2x die Woche. Hat beste Freundesgruppe. Lebt auf dem Boot im Sommer.

BRIDGE
Der Unterschied? Sie traute sich, zum Schnupperkurs zu kommen.
Danach entschied sich alles von selbst.
```

---

## STAR Framework (Situation-Task-Action-Result)

**Best für:** Erfolgsgeschichten, Erfolgsquoten von Kursen, Anfänger-Gewinne

**Struktur:**
```
Situation (1 Zeile): Wer? Wo? Wann?
Task (1 Zeile): Was war die Herausforderung?
Action (2 Zeilen): Was tat diese Person konkret?
Result (1 Zeile): Was war das Ergebnis?
```

**Beispiel (Fahrschule):**
```
SITUATION
Tim: 17 Jahre alt, erste Fahrstunde jemals.

TASK
Angst vor Verkehr. Hatte überhaupt keine Kontrolle.

ACTION
Er kam 3x die Woche für 4 Wochen.
Jeder Tag ein bisschen besser. Jeder Tag ein bisschen weniger Angst.

RESULT
Nach 4 Wochen: Bestandene Prüfung. Heute: Bester Fahrer seiner Klasse.

CTA
Das kannst du auch.
```

---

## SLAY Framework (Story-Lesson-Actionable-You)

**Best für:** Tipps, Learnings, „wie du es machst"

**Struktur:**
```
Story (2 Zeilen): Was ist passiert?
Lesson (1 Zeile): Was hast du gelernt?
Actionable (2 Zeilen): 2–3 konkrete Schritte
You (1 Zeile): Aufforderung an Leser
```

**Beispiel (Tennisverein):**
```
STORY
Mark kam in den Club als Anfänger. Schlechter Serve. Wollte fast aufgeben.

LESSON
Der Durchbruch: Der Serve ist 80% Technik, 20% Kraft.

ACTIONABLE
1. Grip aufs Video überprüfen (nicht wie du meinst — wie es richtig ist)
2. Jeden Tag 10 Serves üben (nicht 50 falsch — 10 richtig)
3. Video-Feedback fragen (von Trainer oder App)

YOU
Probier diese Woche. Sag mir Bescheid, wenn's besser wird.
```

## Mobil-Optimierung (CRITICAL)

**Alle Posts müssen auf Handy lesbar sein:**

```
☑ Kurze Sätze (max 12 Worte)
☑ Absätze (Blank Lines zwischen Sätzen — nicht ein Textblock)
☑ Zahlen + Punkte (nicht ganzen Text)
☑ Emojis sparsam (1 pro 50 Worte)
☑ Länge: 200–250 Worte (nicht 500)
☑ CTA am Ende (nicht versteckt)
```

**Beispiel (mobile formatting):**

```
❌ FALSCH (Textblock):
„Der häufigste Fehler beim Serve ist, dass Anfänger zu viel Kraft nutzen und dabei die Technik vergessen. Das Problem ist, dass man so nie die richtige Kontrolle bekommt und ständig in den Netz oder zu lang spielen. Der Geheimtipp ist, erst auf Technik zu fokussieren und dann Kraft hinzufügen. Das sehen Profis und das sollten auch Anfänger tun."

✅ RICHTIG (Formatiert):
Der häufigste Fehler beim Serve:
Zu viel Kraft.

Resultat?
Ball im Netz oder zu lang.

Die Lösung:
Technik zuerst.
Kraft später.

Das ist, wie Profis es machen.
```

## Quick-Selector (welches Framework?)

**Schau den Post-Typ an:**

```
Wenn du ein Angebot/Event hast → AIDA
Wenn du eine Erfolgsstory erzählst → STAR oder BAB
Wenn du einen Tipp/Fehler zeigst → PAS
Wenn du ein Learning teilst → SLAY
Wenn du unsicher bist → PAS (funktioniert für alles)
```

## Copy-Tipps pro Framework

### PAS
- **Problem:** Konkret, nicht generisch („falscher Grip" nicht „schlechte Technik")
- **Agitate:** Gefühl, nicht nur Fakten („Frustration" nicht „suboptimal")
- **Solve:** Schritt für Schritt, nicht alles auf einmal

### AIDA
- **Attention:** Zahl oder Überraschung (nicht: „Schau dir das an")
- **Interest:** Warum SIE es brauchen (nicht: warum WIR es anbieten)
- **Desire:** Konkret, was ist drin (nicht: „viele Vorteile")
- **Action:** Link, kein „weitere Infos"

### BAB
- **Before:** Sympathie (kein „ihr seid dumm vorher")
- **After:** Konkret, nicht übertrieben
- **Bridge:** Der Club ist die Ursache, nicht nur Kontext

### STAR
- **Situation:** Real Person oder Type (nicht hypothetisch)
- **Task:** Schwierig, aber nicht hoffnungslos
- **Action:** Konkrete Schritte (nicht „sie war nur engagiert")
- **Result:** Beeindruckend, aber erreichbar

### SLAY
- **Story:** Hook (nicht: „Es war einmal")
- **Lesson:** Nicht offensichtlich (nicht: „Übung macht perfekt")
- **Actionable:** 2–3 Steps, nicht 10
- **You:** Direkt, nicht „hoffentlich probierst du's"

## Workflow (schnell)

1. **Framework wählen** (3 Sekunden — obige Tabelle nutzen)
2. **Rohtext/Idee notieren** (2 Minuten)
3. **Template anwenden** (3 Minuten)
4. **Mobile-Check** (1 Minute)
5. **Publish** (30 Sekunden)

**TOTAL: 6–7 Minuten pro Post**

## Häufige Fehler

| Fehler | Folge | Fix |
|--------|-------|-----|
| Framework nicht klar struktur | Text-Block, nicht lesbar | Leerzeilen zwischen Sections |
| Zu lange (500+ Worte) | Leser scrollen weg | Auf 200–250 Worte kürzen |
| CTA zu subtil | User wissen nicht, was tun | Explizit: „[Link] Buchen" oder „Kommentar: Ja!" |
| Keine Emojis | Wirkt steif | 1–2 Emojis strategisch |
| Nur Text, kein Break | Monoton | Zwischen Sections Blank Lines |
| Framework falsch gewählt | Passt nicht zur Message | PAS = Problem zeigen, STAR = Erfolgsgeschichte |
