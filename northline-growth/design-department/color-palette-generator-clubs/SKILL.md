# Farb-Palette-Generator für Clubs

Deine Aufgabe: Eine **harmonische, Club-spezifische Farbpalette** auswählen oder generieren — Primärfarbe, Akzentfarbe, Neutrale Farben, mit Kontrast-Prüfung.

**Warum?** Damit alle Designs (Website, Ads, Social Media) die gleiche visuelle Sprache sprechen.

---

## Farbpsychologie (Schnell verstehen)

```
Dunkelblau (#1B3A6B)
→ Bedeutung: Vertrauen, Professionalität, Sicherheit
→ Best für: Golfclub, Fahrschule, Finance
→ Mood: Konservativ, seriös, elegant

Grün (#2D8659)
→ Bedeutung: Energie, Natur, Wachstum, Gesundheit
→ Best für: Tennisverein, Outdoor, Wellness
→ Mood: Frisch, freundlich, aktiv

Dunkelgrün (#1D4D3E)
→ Bedeutung: Natur, Ruhe, Authentizität
→ Best für: Segelclub, Naturverbunde
→ Mood: Abenteuer, entspannt, nachhaltig

Rot (#D32F2F)
→ Bedeutung: Achtung, Energie, Handlung
→ Best für: CTA-Buttons, Alerts, Dringlichkeit
→ Mood: Intensiv, schnell, Aufmerksamkeit

Orange (#E67E22)
→ Bedeutung: Freude, Kreativität, Warmth
→ Best für: Youth, Energie, Spaß
→ Mood: Einladend, optimistisch, lebendig

Gold (#D4AF37)
→ Bedeutung: Luxus, Tradition, Besonderheit
→ Best für: Premium Clubs, Akzent-Farbe
→ Mood: Elegant, wertvoll, exklusiv

Grau (#F5F5F5 oder #666666)
→ Bedeutung: Neutral, Professionalität
→ Best für: Backgrounds, Text, Struktur
→ Mood: Clean, minimalistisch, lesbar
```

## Kontrast-Checker (WCAG AA Standard)

**Regel:** Text zu Background muss minimum 4.5:1 Kontrast haben.

```
Prüfe mit: https://webaim.org/resources/contrastchecker/

Beispiel Classic-Palette:
- Dunkelblau (#1B3A6B) auf Weiß (#FFFFFF) = 7.2:1 ✅ SEHR GUT
- Gold (#D4AF37) auf Dunkelblau (#1B3A6B) = 5.6:1 ✅ GUT
- Charcoal (#2C2C2C) auf Hellgrau (#F5F5F5) = 8.1:1 ✅ SEHR GUT
- Charcoal (#2C2C2C) auf Weiß (#FFFFFF) = 12.6:1 ✅ PERFEKT

Wenn Kontrast < 4.5:1:
→ Farbe ändern oder
→ Text-Größe/Gewicht erhöhen oder
→ Background ändern
```

## Farb-Anwendung pro Element

```
NAVIGATION/HEADER:
- Background: Primärfarbe (z.B. Dunkelblau)
- Text: Weiß oder Hellgrau
- Links: Weiß, Hover = Akzentfarbe (z.B. Gold)

HERO-SECTION:
- Background: Primärfarbe Gradient oder Bild mit Overlay
- Text: Weiß
- CTA-Button: Akzentfarbe

HEADLINES (H1–H3):
- Color: Primärfarbe oder Dunkelgrau
- Keine Hellfarben für Headlines

BODY-TEXT:
- Color: Dunkelgrau oder Charcoal
- Nicht schwarz (zu hart)
- Nicht Hellfarben (unlesbar)

BUTTONS:
- Primary-Button: Akzentfarbe Background, Dunkeltext
- Secondary-Button: Outline (Border = Primärfarbe, Text = Primärfarbe)
- Hover-State: Dunklere Variante oder Akzentfarbe

CARDS/BOXES:
- Background: Hellfarbe (Hellgrau, Beige, Hellblau)
- Border: 1px, Primärfarbe oder Hellgrau
- Schatten: subtil (0px 2px 8px rgba(0,0,0,0.08))

ALERTS/MESSAGES:
- Success (grün): #51CF66 Background, dunkelgrün Text
- Error (rot): #FF6B6B Background, dunkelrot text
- Warning (orange): #FFA500 Background, dunkeltext
- Info (blau): Primärfarbe Background, weiß text

BACKGROUNDS:
- Main: Weiß #FFFFFF
- Sections: Hellgrau #F5F5F5 (abwechselnd mit Weiß)
- Dark-Sections: Primärfarbe mit weißem Text

BORDERS/LINES:
- Light: Hellgrau #E0E0E0
- Standard: Hellgrau #D0D0D0
- Emphasis: Primärfarbe oder Akzentfarbe
```

## Hex-Code-Export (für Developer)

Gib diesen Text deinem Web-Developer:

```css
/* [Clubname] Color Palette */

:root {
  --color-primary: #1B3A6B;      /* Dunkelblau - Headlines, Links */
  --color-accent: #D4AF37;       /* Gold - CTAs, Hover */
  --color-secondary: #F5F5F5;    /* Hellgrau - Backgrounds */
  --color-text: #2C2C2C;         /* Charcoal - Body-Text */
  --color-background: #FFFFFF;   /* Weiß - Main-Background */
  
  /* Extended Palette */
  --color-success: #51CF66;      /* Grün - Success-Messages */
  --color-error: #FF6B6B;        /* Rot - Error-Messages */
  --color-warning: #FFA500;      /* Orange - Warnings */
  --color-info: #1B3A6B;         /* Blau - Info */
  
  --color-light-gray: #F5F5F5;   /* Light Gray */
  --color-dark-gray: #333333;    /* Dark Gray */
}

/* Anwendungen */
h1, h2, h3 { color: var(--color-primary); }
p { color: var(--color-text); }
a { color: var(--color-primary); }
a:hover { color: var(--color-accent); }

.btn-primary {
  background: var(--color-accent);
  color: var(--color-primary);
}

.card {
  background: var(--color-secondary);
  border: 1px solid var(--color-light-gray);
}
```

## Workflow (Farbe auswählen/exportieren)

1. **Club-Typ definieren** (Golf? Tennis? Segel? Fahrschule?) — 1 Min
2. **Template wählen** (Classic? Energetic? Natural?) — 1 Min
3. **Kontrast prüfen** (alle Kombinationen testen) — 5 Min
4. **Hex-Codes exportieren** (oben Copy-Paste) — 1 Min
5. **Developer geben** (CSS Variables mit Farben) — Done

**TOTAL: 8–10 Minuten**

---

## Häufige Fehler

| Fehler | Folge | Fix |
|--------|-------|-----|
| Zu viele Farben (5+) | Wirkt chaotisch | Max 3–4 Farben: 1 primär, 1 akzent, 2 neutral |
| Farben zu ähnlich | Keine Unterscheidung | Kontrast: Dunkel + Hell, z.B. Dunkelblau + Gold |
| Kontrast < 4.5:1 | Text unlesbar auf Hintergrund | Prüfe mit webaim.org/resources/contrastchecker/ |
| Buttons sind unsichtbar | Kontrast-Problem | Gold auf Gold funktioniert nicht → ändern |
| Keine Consistency | Jede Seite sieht anders aus | Hex-Codes in CSS-Variablen, überall nutzen |
| Hellfarben für Headlines | Unlesbar | Headlines immer dunkel (Primärfarbe oder Charcoal) |
