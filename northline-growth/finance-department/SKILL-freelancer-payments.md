# Freelancer-Payment-Tracking

Deine Aufgabe: **Freelancer-Leistungen tracken, Rechnungen schreiben, Zahlungen verwalten** — damit alle rechtzeitig bezahlt werden und die Kosten korrekt sind.

**Warum?** Damit Freelancer zufrieden sind, keine Fehler bei Rechnungen passieren und Northline die Kosten kontrolliert.

---

## Northline Freelancer-Team & Raten

### Video-Producer/Schnitt

```
Rollen:
- Drehgag (2–3h vor Ort, Kameraarbeit + Basis-Schnitt)
- Schnitt (Rohvideo → 3–5 fertige Reels in 48h)
- Effekte/Musik (Color Grade, Captions, Sound)

Rate-Struktur:
- Option 1: Pauschal pro Drehtag: €400–600 (inkl. Schnitt)
- Option 2: Stundensatz: €40–60/h (für flexible Jobs)
- Option 3: Pro Reel: €60–100 pro fertige Reel

Empfehlung für Northline:
→ €500 Pauschal pro Drehtag (2h Dreh + 6h Schnitt)
→ = €62.50/h bei 8h Gesamtaufwand (fair für Freelancer)

Kosten pro Client/Monat:
- 1× Drehtag monatlich = €500
- Oder: 8h Schnitt/Effekte = €320–480
```

- Meta-Management: €600/Monat
- Oder: 5h/Woche = €1,000–1,400/Monat (höher)

## Leistungs-Tracking Template

Erstelle für jeden Freelancer ein Tracking-Sheet (Google Sheets oder Excel).

### Template "Freelancer Tracking — [Name]"

```
Spalten:
| Datum | Client | Aufgabe | Stunden | Sätze | Betrag | Status | Notizen | Rechnung |
|-------|--------|---------|---------|-------|--------|--------|---------|----------|

Beispiel-Zeile:
| 15.8 | Golfclub | Drehtag | 8h | €500 (Pauschal) | €500 | ✅ Done | 5 Reels schneiden | Pending |
| 20.8 | Tennis | Instagram-Posts | 4h | €40/h | €160 | ✅ Done | 4 Posts + Captions | Pending |
| 22.8 | Segel | Campaign-Setup | 6h | €50/h | €300 | ✅ Done | Meta-Setup + Budgets | Ready |

Formulas:
- Betrag = Stunden × Sätze (oder Pauschal)
- Monthly Total = SUM(Betrag für diesen Monat)
- Status: 🟢 Done / 🟡 In Progress / ⏳ Pending
```

## Payment-Schedule (Wann zahlen?)

```
STANDARD-PLAN (Monatlich):
- Invoice erstellt: 1.–5. des Monats (für Vormonat)
- Zahlung fällig: 15. des laufenden Monats
- Zahlung gemacht: 10.–15. des Monats (pünktlich)

BEISPIEL:
- August-Arbeit → Invoice 1. September → Zahlung 15. September

WICHTIG:
☐ Freelancer sollte Invoice schreiben (nicht Northline)
☐ Invoice muss Adresse, Steuernummer, Datum, Betrag haben
☐ Archiviere alle Invoices (für Steuererklärung)
☐ Check: Rechnungssumme = Tracking Sheet
```

## Monatliches Freelancer-Payment Workflow

### Schritt 1: Leistungen validieren (bis 5. des Monats)

```
Für jeden Freelancer:
☐ Tracking-Sheet durchgehen (alle Aufgaben erledigt?)
☐ Qualität checken (Posts gut? Videos in Ordnung? Schnitt okay?)
☐ Rechnungssumme mit Tracking-Sheet vergleichen
☐ Genehmigung: ja → Zahlungsanweisung
```

### Schritt 2: Invoice anfordern (bis 5. des Monats)

```
Email an Freelancer:

"Hi [Name],

Bitte schreib eine Invoice für August bis [Datum] mit folgendem:

Client-Aufgaben:
- Golfclub: 1× Drehtag (€500)
- Tennis: 4h Social Media (€160)
- Segel: 6h Meta Ads (€300)

Total: €960

Sende die Invoice bis [Datum], dann zahle ich bis [Fälligkeitsdatum].

Danke,
[Name]"
```

### Schritt 3: Invoice prüfen & archivieren

```
Checklist pro Invoice:
☐ Korrekte Rechnungsnummer (fortlaufend)?
☐ Korrekte Rechnungssumme?
☐ Freelancer-Adresse vollständig?
☐ Zahlungsbedingungen klar?
☐ Unterschrift/Stempel (falls gewünscht)?

Archivierung:
- Speichere als PDF: "[Month]-[Freelancer]-Invoice.pdf"
- Speicherort: /Finance/Invoices/2026/August/
- Backup: Google Drive + lokale Festplatte
```

### Schritt 4: Zahlung veranlassen

```
Überweisungsdetails:
- Betrag: [Total aus Invoice]
- Kontoinhaber: [Freelancer Name]
- IBAN: [aus Invoice oder vorherig gespeichert]
- Referenz: "Invoice [Nummer] — August 2026"
- Fälligkeitsdatum: [14 Tage nach Invoice-Datum]

Im Banking:
☐ Betrag eingeben
☐ Referenz eingeben (für Zuordnung)
☐ Bestätigung checken
☐ Zahlungsanweisung freigeben
```

### Schritt 5: Zahlungsbestätigung

```
Nach Zahlung:
☐ Kontobewegung checken (wirklich abgegangen?)
☐ Freelancer benachrichtigen: "Zahlung überwiesen, sollte in 1–2 Tagen ankommen"
☐ Zahlungsdatum im Tracking-Sheet eintragen
☐ Status: ✅ Paid
```

## Häufige Fehler

| Fehler | Folge | Fix |
|--------|-------|-----|
| Keine Invoices (oral bezahlt) | Keine Belege für Steuern, Freelancer vergisst | Immer Invoice + Archivierung |
| Invoice-Fehler (falsche Summe) | Zahlungsverzögerung, Verwirrung | Bevor Zahlung: Invoice vs. Tracking-Sheet checken |
| Verzögerte Zahlungen (>30 Tage) | Freelancer verliert Vertrauen, kündigt | Zahle pünktlich, max. 14 Tage nach Invoice |
| Kein Leistungs-Tracking | Bezahlst falsche Summen | Daily/Weekly eintragen, nicht erst am Monatende |
| Zu hohe Raten | Budget bleibt über, Gewinn sinkt | Raten realistisch verhandeln (Benchmarks nutzen) |
| Keine Backup-Invoices | Verlust von Belegen | PDF speichern + Cloud-Backup |
